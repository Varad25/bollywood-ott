# Access Bollywood — New Titles (Stremio addon)

A catalog-only Stremio addon built from the daily Access Bollywood monitor.
It does **not** provide streams — it's a Discover/watchlist addon: it shows
you what's newly added, grouped the same way the daily alerts are, and each
entry tells you which platform it's on so you can open it in that platform's
own app.

## Catalogs (9)

- **Access Bollywood Alerts — Movies / Series**: only the titles the daily
  monitor actually alerted on (Hindi-first filter applied), with the alert
  date in each description. Currently 15 titles (Oct 28 – Nov 6, 2026):
  Baththa, Dhindora S1, Akka S1, How to Ruin Diwali S1, Meethe Mein Kya Hai,
  Mirzapur: The Movie, Love Always S1, Manmarziyaan, Raanjhanaa, Rockstar,
  Chhota Bheem S20 + 2 spin-offs, Dilwali Diwali, Last Man in Tower.
- **Per-platform Newly Added** (Netflix, Amazon Prime, Hulu, Zee5):
  each platform's full current "Newly Added" list from Access Bollywood —
  76 titles at build time (Netflix 47, Prime 10, Hulu 10, Zee5 9).

## Run it

Needs Node 18+, no packages to install.

```bash
node addon.js
# → Access Bollywood addon listening on http://127.0.0.1:7000/manifest.json
```

Then in Stremio: **Add-ons → paste `http://127.0.0.1:7000/manifest.json`**
in the addon URL box and install. (Use `PORT=7001 node addon.js` to change
the port. Stremio must be running on the same machine, or host the addon
somewhere reachable and use that host's manifest URL instead.)

## Keeping it current

- **On Cosmo's VM** the addon reads the monitor's `snapshot.md` live, so
  the per-platform catalogs update automatically after each daily check —
  just leave the server running there (or restart it; data is read per
  request).
- **Anywhere else**, it falls back to the bundled `catalog-data.json`.
  Refresh that copy with `node update-from-snapshot.js <path-to-snapshot.md>`.
- **New alerts**: append one line per alerted title to `titles.json`:
  `{"title": "<exactly as alerted>", "platform": "Netflix", "alertDate": "YYYY-MM-DD"}`
  That file is the permanent, growing record — titles never rotate out of
  the Alerts catalogs, unlike the site's Newly Added lists.

## Files

- `addon.js` — the addon server (zero dependencies, plain Node `http`)
- `titles.json` — alerted titles (the ones sent to chat)
- `catalog-data.json` — frozen per-platform Newly Added data (generated)
- `update-from-snapshot.js` — regenerates `catalog-data.json` from a snapshot
- `package.json` — `npm start` runs the server, `npm test` sanity-checks it

## Limits

- No posters/backdrops (Access Bollywood lists are text-only) — Stremio
  shows its placeholder artwork.
- No playback links: Netflix/Prime/Hulu/Zee5 titles play in their own apps.
- Series entries are show-level (with the season noted in the description);
  there are no episode lists.

## Hosting on GitHub (Pages — free, no server)

Stremio addons are just HTTPS GETs of JSON, so the catalog side works as
static files. This repo ships a ready-made static export in `docs/`
(164 files: manifest, 9 catalogs, meta + empty-stream JSON for 76 titles),
generated by `npm run build` and verified locally.

1. Push this folder as a GitHub repo (e.g. `stremio-access-bollywood`).
2. Repo **Settings → Pages → Build and deployment → Deploy from a branch →
   `main` / `/docs`**.
3. Your addon URL is then:
   `https://<your-github-username>.github.io/stremio-access-bollywood/manifest.json`
   Paste that into Stremio's Add-ons screen on any device.

Static limits vs. the live Node server: no in-catalog search box results
and no pagination extras — irrelevant here (largest catalog: 47). Playback
is unaffected (catalog-only either way).

Updates: the daily Access Bollywood check now also appends each newly
alerted title to `titles.json` and re-runs `npm run build`, so `docs/`
stays current on Cosmo's machine; publishing is just pushing the changed
`titles.json`, `catalog-data.json`, and `docs/` files to the repo.
